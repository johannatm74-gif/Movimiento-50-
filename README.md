# Movimiento 50 Pro v3 — Flujo automático + Avatar humano 3D

Cambios:
- Las 4 rutinas están habilitadas.
- Los ejercicios avanzan automáticamente cuando termina el tiempo.
- Hay una transición de 5 segundos mostrando el siguiente ejercicio.
- Botón de pausa y botón para saltar al siguiente.
- Avatar femenino SVG con sombreado y volumen 3D; ya no usa el muñeco CSS básico.
- Cada ejercicio aplica un movimiento diferente al esqueleto visual.
- Registro local de presión arterial y progreso.

Importante: esta es una app de bienestar, no un dispositivo médico ni una herramienta diagnóstica.
