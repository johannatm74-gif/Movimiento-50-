# Movimiento 50 Pro v4 — Voz + temporizador + avance automático

Incluye:
- Las cuatro categorías de rutinas.
- Temporizador por ejercicio.
- Avance automático al siguiente ejercicio.
- Pausa y salto manual.
- Voz en español mediante Speech Synthesis del teléfono/navegador.
- Botón para activar/desactivar la voz.
- Aviso hablado del ejercicio actual y del siguiente.
- Recurso visual de referencia `assets/humano_3d_referencia.png`, basado en la imagen elegida.
- Avatar animado de la app para demostrar el movimiento.

Nota técnica: una imagen PNG fija no contiene articulaciones 3D, por lo que no puede convertirse por sí sola en una animación anatómica real. La app conserva el motor de movimiento animado y guarda la imagen seleccionada como referencia visual. Para movimiento humano fotorrealista por ejercicio se requieren clips/animaciones independientes o un modelo 3D riggeado.
