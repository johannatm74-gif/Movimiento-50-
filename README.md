# Movimiento 50 Pro — v1

Primera versión funcional pensada para móvil.

Incluye:
- Inicio accesible.
- Rutina Fuerza suave con 5 ejercicios.
- Avatar humano animado mediante CSS.
- Chequeo previo.
- Registro local de presión arterial.
- Registro de síntomas de menopausia.
- Bloqueo preventivo si la presión ingresada es >180 sistólica o >120 diastólica.
- Feedback final y progreso local.
- Navegación Inicio / Rutinas / Mi salud / Progreso.

## Uso
Sube todos los archivos del ZIP a la raíz de tu repositorio GitHub.
Con GitHub Pages, usa index.html como entrada.

## Nota importante
Esta es una app de bienestar, no un dispositivo médico ni una herramienta diagnóstica.
Los avatares actuales son animaciones CSS funcionales para validar el flujo. En una siguiente versión pueden sustituirse por videos/WebP/GLB 3D manteniendo la misma interfaz.
